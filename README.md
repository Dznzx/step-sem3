# STEP Semester 3 — Java Coursework

All weeks of the STEP Semester 3 Java coursework, consolidated into one repo.

Each week lives on its own pair of branches:
- `feature/weekN/practice` — in-class practice problems
- `feature/weekN/homework` — take-home assignment problems

| Week | Topic |
|---|---|
| 1 | Java Strings |
| 2 | String Operations & Performance |
| 3 | OOP Introduction, Classes and Objects |
| 4 | Programming Fundamentals: Arrays |
| 5 | Java Arrays and Methods (Category C) |
| 6 | Access Modifiers, Encapsulation & Object Modeling |
